# Sukumar Karnam — Network Engineer Portfolio

A cinematic black-and-red editorial portfolio for **Sukumar Karnam (Network Engineer)** built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **GSAP**, and **Lucide React**.

## Quick Start

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Updating Your Information & Portrait

- **`src/data/profile.ts`** — Update your email, LinkedIn URL, GitHub URL, Resume link, optional education period, and Blue Teamers certificate image/verification URL.
- **`src/data/labs.ts`** — Update your progress status across the 12 hands-on networking labs.
- **`public/images/profile-cutout.png`** & **`public/images/profile.png`** — Your actual uploaded studio portrait assets used in the hero section.
